    К разбору —

    AI-вердикт и ваше решение — разные вещи. Список: APPLY → MAYBE → без оценки → SKIP.

    Подходящие вакансии

    По рабочему резюме HeadHunter. За один запуск — до 5 страниц HH (~250 вакансий). Если подходящих больше — «Загрузить ещё» продолжает со следующей страницы, а не с начала. Это может занять несколько минут.

    Ручной поиск с промежуточным выбором вакансий перед добавлением в основной список — появится позже. Сейчас этот режим не запускает импорт в список.
